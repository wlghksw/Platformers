# 작성 스타일 가이드

## 톤

- 전문적이지만 친근하게
- 어려운 개념은 비유를 사용해 쉽게 설명
- 불필요한 형식적 인사말 생략
- "~습니다"체 사용

## 형식

- 문서 출력: Word(.docx) 형식 우선
- 프레젠테이션: 10~15슬라이드, 시각 자료 중심
- 보고서: 항상 Executive Summary를 맨 위에
- 이모지는 SNS용 콘텐츠에서만 사용

## AI 스타일 금지 목록

- "혁신적인", "획기적인", "게임체인저" 같은 과장 표현 금지
- 뻔한 도입부 금지 ("오늘날 빠르게 변화하는...")
- 비유와 실제 사례로 설명할 것
