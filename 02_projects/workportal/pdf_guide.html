  • 멀티턴 대화로 이전 맥락 자동 유지
  • 스크린샷 첨부로 UI 관련 작업도 처리 가능

컨텍스트 폴더 설계 — Claude의 뇌 만들기

폴더 구조 예시

📁 내 프로젝트/ ├── 00_context/ │ ├── 프로젝트_개요.md │ ├── 팀원_정보.md │ └── 용어_사전.md ├── 작업파일/ └── 결과물/

컨텍스트 파일에 담을 내용

  • 프로젝트 목표 및 배경 (1페이지 요약)
  • 핵심 이해관계자 및 역할 정의
  • 자주 쓰는 업계 용어 / 약어 사전
  • 원하는 결과물 형식 및 톤 앤 매너
  • 금기 사항 및 주의 규칙
💡 팁: 세션 시작 시 Claude가 자동으로 00_context/ 폴더를 읽으면 매번 설명할 필요가 없어집니다.
2
글로벌 지침 (CLAUDE.md) — 영구 설정파일

CLAUDE.md 작성 예시

## 커뮤니케이션 - 한국어로 응답 - 간결하고 핵심 위주 ## 결과물 규칙 - 문서: .docx 우선 - 파일명: YYYY-MM-DD_주제 ## 작업 시작 전 - context/ 폴더 먼저 읽기 - 불명확하면 반드시 질문

활용 효과

  • 매 세션마다 동일한 스타일 자동 적용
  • "한국어로 답해줘" 같은 반복 요청 제거
  • 팀 공유 시 일관된 AI 행동 보장
  • 결과물 포맷 통일로 후처리 시간 절감
📍 위치: ~/.claude/CLAUDE.md (전역) 또는 프로젝트 루트에 CLAUDE.md 파일로 저장
3
커스텀 스킬 활용 — 반복 작업 자동화

스킬이란?

  • 특정 작업 처리 방식을 정의한 플러그인
  • 예: PDF 생성, PPTX 제작, 보고서 작성
  • 한 번 설정하면 자동으로 적용됨

기본 제공 스킬

  • 📄 docx — Word 문서 생성
  • 📊 xlsx — 엑셀 스프레드시트
  • 📑 pdf — PDF 처리/생성
  • 🎨 pptx — 프레젠테이션

커스텀 스킬 예시

  • 주간 보고서 자동 생성
  • 특정 포맷 데이터 분석
  • 사내 양식 자동 작성
  • 업무 흐름 자동화

4
서브 에이전트 병렬 처리 — 복잡한 업무 분산 실행

작동 방식

  • 주 Claude가 작업을 여러 서브 에이전트로 분배
  • 각 에이전트가 독립적으로 병렬 실행
  • 결과를 취합해 최종 결과물 완성
  • 긴 작업 시간 → 단시간 완료로 단축

활용 예시

  • 시장 조사 보고서 — 10개 섹션 동시 작성
  • 대량 파일 분류 및 정리 동시 처리
  • 여러 데이터소스 동시 검색·분석
  • 다국어 번역 병렬 처리
⚡ 속도 향상
순차 처리 대비 최대 5~10배 빠른 작업 완료 가능
🎯 품질 향상
각 에이전트가 전문 영역에 집중하여 더 정확한 결과 도출
🔄 유연성
복잡한 워크플로우도 자동으로 단계 분해 및 실행
5
커넥터 기능 (MCP) — 외부 툴 연동

주요 커넥터

  • 📧 Gmail — 이메일 읽기/작성
  • 📁 Google Drive — 파일 관리
  • 📅 Google Calendar — 일정 관리
  • 💬 Slack — 메시지 전송
  • 📝 Notion — 페이지 생성

자동화 예시

  • "오늘 받은 중요 메일 요약해줘"
  • "Drive에 보고서 저장하고 Slack 알림"
  • "캘린더 빈 시간에 미팅 잡아줘"
  • "Notion에 회의록 자동 정리"

커넥터 설정 방법

  • Cowork 설정 → 커넥터 탭 이동
  • 원하는 서비스 선택 및 인증
  • 필요 권한 부여 (읽기/쓰기)
  • 설정 후 즉시 자연어로 사용 가능
6
스케줄 태스크 — 완전 자동화

설정 가능한 스케줄

  • 매일 오전 9시 — 오늘의 일정 브리핑
  • 매주 금요일 — 주간 성과 리포트 생성
  • 매월 1일 — 월간 데이터 분석 보고서
  • 특정 이벤트 발생 시 — 조건부 자동 실행

자동화 효과

  • 반복 업무 완전 제거로 핵심 업무 집중
  • 사람 실수 없는 일관된 품질의 결과물
  • 24시간 무인 운영으로 업무 연속성 확보
  • 커넥터와 결합 시 완전 자동 배포 가능
